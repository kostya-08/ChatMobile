Описание проекта:
Имеются экраны настроек, список чатов, сам чат, и экран профиля.
В базе данных будут храниться контакты.
Приложение будет работать как классический мессенджер, например как телеграм.
План работ:
Начну со страницы со списком чатов и самого чата с пользователем, далее сделаю меню профиля а после настроек, после подвяжу базы данных и связи через мировую паутину.
Технологии: 
Основной язык программирования Kotlin, среда разработки Android Studio
